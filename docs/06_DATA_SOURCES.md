## What is simulated, and how it stays honest

The telemetry itself (per-shipment dwell, utilisation, customs hold ...) is produced by a **calibrated event-driven simulator**
(Role 3, Day 0) because no public source gives per-container dwell and outcomes for the whole network. Honesty rules:

1. Baseline levels/seasonality per node come from real calibration numbers (PortWatch activity, CPPI scale, weather history).
2. Disruption events (strikes, closures, storms, customs surges) are sampled from an **event catalogue** with realistic frequencies/durations; each event raises specific causes (customs, weather, labour, equipment).
3. **The label is generated by outcome dynamics with noise and hidden factors** (e.g. unobserved yard-gang strikes, random equipment faults) - never from a formula of the observed columns. Model scores are expected to land well below 1.0; that is the point.
4. Observed columns have measurement noise and occasional reporting drift/outliers (so EDA has a real noise floor to measure).
5. The simulator's code, parameters and random seed are committed; any teammate can regenerate the data byte-for-byte.
